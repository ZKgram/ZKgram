# ZKgram Desktop: функции, сборка, установка

ZKgram — неофициальный клиент Telegram для Windows на основе
[AyuGram Desktop](https://github.com/AyuGram/AyuGramDesktop) (форк Telegram
Desktop) с функциями, перенесёнными из [Nagram X](https://github.com/risin42/NagramX).
Весь код распространяется под GNU GPL v3.

## Где что находится

Настройки → **Настройки ZKgram** (бывшие «Настройки AyuGram»):

* **AyuGram**: режим призрака и «шпион» (сохранение удалённых и изменённых сообщений);
* **Фильтры**: фильтры сообщений по регулярным выражениям, теневой бан;
* **Основные / Внешний вид / Чаты / Другое**: остальные функции AyuGram;
* **Функции Nagram X**: всё, что перенесено из Nagram X (список ниже).

В меню чата (⋮ в шапке чата) и профиля появился пункт **ZKgram**: закладки
чата, переход к сообщению по ID, локальное имя. В контекстном меню сообщения
есть пункт **В закладки**.

## Функции AyuGram (есть в ZKgram)

* Режим призрака: не читать сообщения и истории, не отправлять «онлайн» и
  «печатает», автоматически уходить в офлайн, читать при ответе, отложенная
  отправка, отправка без звука, исключения по чатам, отдельные настройки на
  каждый аккаунт
* Сохранение удалённых сообщений и истории правок, сохранение вложений,
  исключения, экспорт и импорт базы
* Локальное сохранение даты прочтения и последнего визита
* Фильтры сообщений (regex), общие фильтры и фильтры по чатам, теневой бан,
  скрытие сообщений от заблокированных, фильтр «Zalgo»-символов
* Отключение рекламы и историй, похожие каналы, предупреждение при открытии ссылок
* Локальный Telegram Premium, скрытие премиум-статусов
* Переводчик: Telegram, Google, Yandex, встроенный переводчик Windows
* Режим стримера (скрытие окна от захвата экрана)
* Скриншот сообщений (Message Shot), детали сообщения, ID пользователей и чатов
* Отметки удалённых и изменённых сообщений, полупрозрачные удалённые сообщения
* Шрифты, радиус пузырей, форма аватаров, ширина сообщений, иконка приложения
* Настройка контекстного меню, поля ввода, бокового меню и трея
* Подтверждение отправки стикеров, GIF, голосовых и кружков
* Дата создания аккаунта, взаимные контакты, «Подсмотреть онлайн»
* Пересылка из каналов с запретом пересылки, повтор сообщения, «сжечь» одноразовые медиа
* Удаление всех своих сообщений в группе, переход к началу чата

## Функции Nagram X (перенесены в ZKgram)

| Функция Nagram X | Что сделано в ZKgram |
|---|---|
| Ask Before Calling | Подтверждение перед звонком |
| Ask Before Sending Bot Command | Подтверждение перед отправкой команды бота по клику |
| Ask Before Opening Inline Links | Подтверждение перед открытием любой ссылки, включая t.me и кнопки ботов (Ctrl+клик — без вопроса) |
| Disable Number Rounding | Точные числа просмотров, реакций, участников |
| Name Order | Порядок «Имя Фамилия» / «Фамилия Имя» |
| Set Local Name | Локальное имя для пользователя, группы или канала (видно только тебе) и сброс всех локальных имён |
| Use «Also delete for» by Default | При удалении чата галочка «удалить у собеседника» включена по умолчанию |
| Sticker Size | Размер стикеров (ползунок) |
| Custom Title | Свой заголовок окна |
| DeepL Translator | Переводчик DeepL (нужен бесплатный ключ API) |
| Microsoft Translator | Переводчик Microsoft (без ключа) |
| AI Translator (LLM) | ИИ-переводчик через любой OpenAI-совместимый API: адрес, ключ (можно несколько через запятую), модель, системный промпт, температура |
| Transcribe (Whisper / Workers AI / Gemini) | Расшифровка голосовых и кружков через OpenAI-совместимый Whisper API (например, бесплатный Groq) |
| Bookmarks | Закладки на сообщения: добавить из контекстного меню, список закладок чата и всех чатов |
| Go to Message by ID | Переход к сообщению по его номеру |
| Unblock All / Unblock Deleted | Разблокировать всех или только удалённые аккаунты |
| Export / Import Settings | Резервная копия настроек ZKgram и AyuGram в файл |
| Restart App | Перезапуск приложения |

Функции, которые в Nagram X уже совпадали с AyuGram (режим призрака,
сохранение удалённых, фильтры, теневой бан, локальный премиум, скрытие
историй, отметки, Zalgo-фильтр, секунды во времени, повтор сообщения и т.д.),
в ZKgram есть через код AyuGram.

### Что не перенесено и почему

* Функции, которых нет смысла делать на ПК: камера в кружках, вибрация,
  датчик приближения, push-сервисы (FCM, UnifiedPush, microG), Material You /
  Monet-темы, нижняя панель вкладок, жесты, планшетный режим, системный
  аккаунт Android, карты OSMDroid и Google Maps.
* Функции, которые уже есть в обычном Telegram Desktop: копирование фото и
  стикеров, QR-вход, предпросмотр медиа в списке чатов, пересылка без
  автора и подписи, DNS over HTTPS, прокси.
* Крупные функции, которые пока не перенесены (можно сделать отдельно): облачная
  синхронизация настроек, пароли на отдельные аккаунты и «тревожный» код,
  закреплённые реакции, персидский календарь, Pangu-пробелы для CJK, заметки
  к контактам.

## Сборка

Сборка идёт в GitHub Actions: `.github/workflows/win.yml`.

1. В репозитории: **Settings → Secrets and variables → Actions** добавь
   секреты `TG_API_ID` и `TG_API_HASH` (получить на https://my.telegram.org →
   API development tools).
2. Любой пуш в ветку `main` или кнопка **Actions → Windows build → Run
   workflow** запускает сборку.
3. Первая сборка библиотек занимает несколько часов. Если запуск упал по
   лимиту времени, запусти его ещё раз: собранное сохраняется в кэш.
4. Готовый `ZKgram.exe` появляется в **Releases** (и в артефактах запуска).

## Установка

ZKgram — портативное приложение: распакуй архив в любую папку, например
`C:\Users\<имя>\Desktop\ZKgram`, и запусти `ZKgram.exe`. Данные (вход в
аккаунт, настройки, база удалённых сообщений) хранятся в папке `tdata` рядом с
`ZKgram.exe`; если в эту папку нельзя писать, то в `%APPDATA%\ZKgram Desktop`.
С Telegram Desktop и AyuGram они не пересекаются. Папку `tdata` никому не
передавай: в ней сессия твоего аккаунта.

## Риски

Режим призрака, сохранение удалённых сообщений и вход через свои API-ключи
нарушают условия использования Telegram API. Telegram может ограничить
аккаунт, который пользуется неофициальным клиентом. Пользуйся на свой риск.
